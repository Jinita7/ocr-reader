# OCR Reader Project

This project extracts text from images using Tesseract OCR.

---

## Features
- Extract text from images
- Clean extracted text
- Export to Excel

---

## Tech Stack
- Python
- pytesseract
- Pillow
- pandas

---

##  Requirements
- Tesseract OCR installed on system
- Add Tesseract to PATH  
  https://github.com/UB-Mannheim/tesseract/wiki

---

## How to Run

```bash
python main.py
